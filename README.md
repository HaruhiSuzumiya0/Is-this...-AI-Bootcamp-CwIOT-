# is this... AI?

Datasets :
A = 100% Human, B = 100% AI, C = 50/50

You can change the medias themselves, the number of media, the number of people, the passing order.

- Every media is an image or a video file.
- Images (.jpg .png .svg ...) are shown as images. Articles = a screenshot image.
- Videos (.mp4 .webm .mov .m4v) autoplay muted and loop.
- Any missing file shows placeholder.svg instead.


AI Declaration :

I used claude to help me with how to proceed for the specific order we wanted (Participant 1 gets media 1, Participant 2 gets media 2, etc.. and when the first turn is over; Participant 1 gets media 2, Participant 2 gets media 3 and so on so that everyone gets influenced by someone else's choice) and how to show the end statistics screen as well as the video extension treatment.
